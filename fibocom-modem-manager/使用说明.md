# Fibocom 模组 PC 管理工具（fibocom-modem-manager）使用说明

## 1. 项目作用

这是一个 **Windows 桌面侧** 的 Fibocom 模组管理工具。它把原厂 WEBUI（`WEBUI_V_02.02.28` 前端）内嵌到本地 HTTP 服务中，再通过 USB 串口（或 TCP/UDP AT 通道）把前端请求翻译成 AT 指令，从而在不改动模组固件的情况下使用原厂界面。

- 前端资源内嵌在程序里（`assets/web`），不需要联网。
- 本地只监听 `127.0.0.1` 的随机端口，不对外开放。
- 连接向导页面为 `/local/`，原厂管理界面为 `/`。

## 2. 适用模组

程序内置以下型号配置（`src/profiles.rs`）：

| 模组 | 状态 | 说明 |
|---|---|---|
| FM150AE | 支持 | 高通平台，使用 GT 系列指令 |
| FM160 | 支持 | 高通平台，使用 GT 系列指令 |
| FM170 | 支持 | 高通平台 |
| FM190 | 支持 | 高通平台 |
| FM650 | 支持 | 使用 GT 指令 |
| FM652 | 支持 | 使用 GT 指令 |
| FM350 | 支持 | 非 GT 分支 |

未内置配置的型号（如 FG132、FM360 等）仍可能连上，但部分页面/指令会因平台差异显示为空或报错。FG132 建议使用同目录下的 `fibocom-webui-inmodem` 模组内置方案。

运行环境：Windows 10/11（依赖 `msedge.exe` 或系统默认浏览器）。源码可在其他平台编译，但自动开窗逻辑面向 Windows。

## 3. 前置条件

1. 模组通过 USB 接入 PC，并处于 **包含 AT 串口** 的 USB 模式（如 `Diag+Modem+AT+Pipe+ECM+ADB`）。
2. 设备管理器中能看到 Fibocom 的 USB 串口（默认 `115200 8N1`，程序也会尝试 9600）。
3. 不需要安装模组驱动之外的组件；若使用网络 AT，需要知道 AT 服务的 TCP/UDP 地址与端口。

## 4. 使用方法

### 4.1 直接运行

1. 双击 `Fibocom模组管理工具.exe`。
2. 程序启动本地服务并自动打开 Edge 应用窗口。
3. 首次使用会进入 `/local/` 连接向导：
   - 选择 Fibocom USB 串口与波特率，或填写 TCP/UDP AT 地址；
   - 点击连接。
4. 连接成功后显示原厂管理界面（首页、网络、短信、设备信息等）。
5. 关闭浏览器窗口约 60 秒后，后台进程自动退出。

常用环境变量：

| 变量 | 作用 |
|---|---|
| `FIBOCOM_NO_WINDOW=1` | 不自动打开浏览器，仅启动本地服务 |
| `FIBOCOM_NO_WINDOW` 未设置 | 自动用 Edge 打开 `http://127.0.0.1:<随机端口>/` |

### 4.2 从源码构建

```powershell
cd fibocom-modem-manager
cargo build --release
# 产物：target\release\fibocom-modem-manager.exe
```

调试运行可直接执行 `cargo run --release`。前端与连接向导通过 `include_dir` 编译进二进制，发布时只需一个 exe。

## 5. 配置与数据

配置文件路径：

```text
%APPDATA%\FibocomModemManager\settings.json
```

主要字段：

| 字段 | 默认值 | 说明 |
|---|---|---|
| `last_conn` | 空 | 上次连接方式（串口/TCP/UDP），用于自动连接 |
| `auto_connect` | `true` | 启动时自动连接上次设备 |
| `password` | `admin` | 本地登录密码（前端已做本地会话处理） |
| `language` | `ch` | 界面语言 |
| `timezone` | `8` | 时区 |
| `sms_center` | 空 | 短信中心号 |

## 6. 验证与排错

- 程序启动后控制台/窗口会打印 `http://127.0.0.1:<端口>`，可直接在浏览器打开。
- 首页能显示设备信息，说明串口 AT 通信正常。
- 若提示连接失败：
  1. 确认模组 USB 模式包含 AT 口；
  2. 换一个 Fibocom 串口（部分模式会暴露多个口）；
  3. 降低波特率到 9600 再试；
  4. 关闭其他占用该串口的工具（如串口助手、AT 工具）。
- 若页面能打开但数据全空，通常是 AT 指令集不匹配或该型号未内置配置，可改用 `fibocom-webui-inmodem`。

## 7. 能力边界

- 仅做 PC 侧管理，不写入模组固件，不取代模组内置 Web。
- 在线升级、下载、部分以太网/WLAN/访客网络页面只做占位返回，不支持真实操作。
- 短信发送、PIN 解锁、选网等操作依赖模组 AT 指令支持情况。
- 电脑关机或关闭窗口后服务停止，不能作为模组的常驻 Web 服务。

## 8. 相关目录

| 路径 | 说明 |
|---|---|
| `assets/web` | 内嵌的原厂 WEBUI（02.02.28） |
| `assets/local` | `/local/` 连接向导页面 |
| `src/api.rs` | `/fibo/webapi` JSON-RPC 方法实现 |
| `src/transport.rs` | 串口/TCP/UDP AT 传输层 |
| `src/profiles.rs` | 型号与指令差异配置 |
