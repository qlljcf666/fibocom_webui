# Fibocom FG652 / FM650 模组内置 WebUI（UDX710）使用说明

## 1. 项目作用

把原厂 WEBUI（`WEBUI_V_02.02.28`，104 个站点文件）通过 **adb** 安装到 FG652/FM650（UNISOC UDX710）模组 Linux 内部，并自带一个纯 Go 静态后端：

- 提供 `/` 静态页面与 SPA 回退；
- 实现 `/fibo/webapi`（JSON-RPC）与 `/fibo/fibologin/`；
- 通过模组 AT 通道读取/设置模组状态；AT 通道被 ofono 占用时，自动回退到 `org.ofono.Modem.SendAtcmd`；
- 绑定 `0.0.0.0`，不依赖互联网。路由模式、网桥模式只要拿到 `192.168.x.x` 地址即可访问。

本方案不依赖 UDX710 原厂 Web 服务，也不依赖高通的 QCMAP、lighttpd、`libfibosocket`；与 `UDX710-TOOLS-main` 相互独立，可同时安装。

## 2. 适用模组与平台

| 模组 | 平台 | 架构 | 状态 | 说明 |
|---|---|---|---|---|
| FG652-CN / FG652-EU | UNISOC UDX710 | aarch64 | 适配 | 使用 `fiboweb-arm64` |
| FM650-CN / FM650-EU | UNISOC UDX710 | aarch64 | 适配 | 使用 `fiboweb-arm64` |

参考项目 `UDX710-TOOLS-main` 的关键约定：

- 程序与插件放在 `/home/root/6677`；
- 持久化配置放在 `/mnt/data`（如 `mode.cfg`）；
- 模组 AT 由 **ofono** 管理，通过 `org.ofono.Modem.SendAtcmd` 收发（`gdbus` / `dbus-send`）。

其他 UDX710 设备只要满足“可 adb root、有可写分区、能通过 `/dev/ttyAT` 或 ofono 执行 AT”，也可以使用；程序不锁定型号。

## 3. 前置条件

1. `adb devices` 能看到设备，且具有 root 权限（`adb root` 后一般为 root）。
2. 模组内有可写且可执行的分区。安装目录按以下顺序自动选择：
   `/mnt/data → /home/root → /usrdata → /data → /userdata → /opt`。
   FG652/FM650 通常落在 `/mnt/data/fibocom-webui` 或 `/home/root/fibocom-webui`。
3. 目标端口空闲：默认按 `80 → 8080 → 8000 → 8088` 自动选择。
4. AT 通道可用：`/dev/ttyAT` 等直连端口，或 ofono D-Bus（推荐，UDX710 默认由 ofono 占用 AT）。

## 4. 安装方法

### 4.1 构建

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
# 也可直接双击 build.bat
```

产物在 `dist/`：`bin/fiboweb-arm64`（UDX710 使用）、`bin/fiboweb-arm`、`www/`、`install.sh`、`uninstall.sh`。

### 4.2 一键安装（推荐）

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\push.ps1
# 多设备或指定端口
powershell -ExecutionPolicy Bypass -File .\tools\push.ps1 -Serial <序列号> -Port 80
```

`push.ps1` 会自动识别 `uname -m`：`aarch64` 只推送 `fiboweb-arm64`，并逐文件推送 `www`，避免不同 adb 版本目录嵌套。

### 4.3 手动安装

```powershell
adb root
adb shell "rm -rf /data/local/tmp/fiboweb-install; mkdir -p /data/local/tmp/fiboweb-install/bin /data/local/tmp/fiboweb-install/www"
adb push dist\bin\fiboweb-arm64 /data/local/tmp/fiboweb-install/bin/
adb push dist\install.sh /data/local/tmp/fiboweb-install/
adb push dist\uninstall.sh /data/local/tmp/fiboweb-install/

$www = (Resolve-Path "dist\www").Path
Get-ChildItem "dist\www" -Recurse -Directory | ForEach-Object {
    $rel = $_.FullName.Substring($www.Length).Replace('\','/')
    adb shell "mkdir -p '/data/local/tmp/fiboweb-install/www$rel'"
}
Get-ChildItem "dist\www" -Recurse -File | ForEach-Object {
    $rel = $_.FullName.Substring($www.Length).Replace('\','/')
    adb push $_.FullName "/data/local/tmp/fiboweb-install/www$rel"
}

adb shell sh /data/local/tmp/fiboweb-install/install.sh
```

### 4.4 安装目录与文件

下文用 `<安装目录>` 表示自动选择后的路径（FG652/FM650 常见为 `/mnt/data/fibocom-webui` 或 `/home/root/fibocom-webui`）。

| 文件 | 作用 |
|---|---|
| `<安装目录>/bin/fiboweb` | 后端二进制（aarch64） |
| `<安装目录>/www` | 原厂 WEBUI 站点 |
| `<安装目录>/etc/listen` | 监听地址（默认 `auto`） |
| `<安装目录>/etc/port` | 实际监听端口 |
| `<安装目录>/etc/config.json` | AT 通道、语言、时区、短信中心 |
| `<安装目录>/bin/fibowebctl` | start/stop/restart/status |
| `<安装目录>/var/fiboweb.log` | 运行日志 |

### 4.5 图形化管理工具（GUI）

- 双击 `启动GUI.bat`（优先启动 `FibocomWebUI.exe`）；
- 或直接双击 `FibocomWebUI.exe`；
- 或源码运行：`python gui\fiboweb_gui.py`。

主要功能：设备枚举、一键安装、重新构建并安装、启动/停止/重启、状态面板（含“适配检测”：安装目录、根分区只读、ofono 状态）、日志、`adb forward` 打开管理页、卸载。

打包 exe：

```powershell
powershell -ExecutionPolicy Bypass -File .\gui\build_exe.ps1
# 产物：项目根目录 FibocomWebUI.exe
```

## 5. AT 通道与 ofono 回退

### 5.1 探测顺序

1. `FIBOWEB_AT` / `FIBOWEB_AT_CANDIDATES` / `etc/config.json` 中显式配置；
2. ofono（`ofono:/ril_0`、`/ril_1`、`/ril_2`，经 `gdbus` 或 `dbus-send` 调用 `SendAtcmd`）；
3. 直连串口（atrouter 会占用其中 `stty_lte*`，故放在 ofono 之后）：

```text
/dev/ttyAT, /dev/ttyAT0, /dev/ttyAT1,
/dev/stty_lte4, /dev/stty_lte5, /dev/stty_lte6, /dev/stty_lte7,
/dev/ttyGS0, /dev/ttyGS1, /dev/smd11, /dev/smd9, /dev/smd7, /dev/smd8,
/dev/at_mdm0, /dev/ttyHS0, /dev/ttyMSM0
```

可用环境变量或 `etc/config.json` 覆盖：

```sh
FIBOWEB_AT=/dev/ttyAT
FIBOWEB_AT_CANDIDATES=/dev/ttyAT,/dev/ttyGS0
```

### 5.2 ofono 回退（UDX710 推荐）

FM650 的 `/etc/atrouter/system.ini` 中 `CPChnl0..3=/dev/stty_lte4..7` 由 atrouter 独占，直连可能抢占其通道，因此默认先走 ofono。若 ofono 可用，程序自动尝试：

```sh
gdbus call --system --dest org.ofono --object-path /ril_0 \
  --method org.ofono.Modem.SendAtcmd "AT+CSQ"
# 或
dbus-send --system --print-reply --dest=org.ofono /ril_0 \
  org.ofono.Modem.SendAtcmd string:"AT+CSQ"
```

- 默认依次探测 `/ril_0`、`/ril_1`、`/ril_2`；
- 可指定路径：`FIBOWEB_OFONO_PATH=/ril_1`，或设置 `FIBOWEB_AT=ofono:/ril_1`；
- 短信在 ofono 模式下走 `org.ofono.SmsManager.SendMessage`，不依赖 `AT+CMGS` 两步流程。

## 6. 开机自启

安装脚本按目标系统自动选择：

1. **systemd**：写入 `/etc/systemd/system/fiboweb.service`，`systemctl enable/restart`；单元带 `RequiresMountsFor=<安装目录>` 与 `After=data-mount.service`。
2. **OpenWrt procd**（`/etc/rc.common` 存在）：写入 `/etc/init.d/fiboweb`，procd 托管。
3. **SysV init（UDX710 / FM650）**：写入 `/etc/init.d/fiboweb`，并创建 `/etc/rc5.d/S99fiboweb` 符号链接（`/etc/inittab` 默认 `initdefault:5`，`rcS` 只执行 `/etc/rc<runlevel>.d/S*`，不会执行 `/etc/init.d/S*`）。
4. **其他**：向 `/etc/rc.local` 追加启动块。

根分区默认只读时，脚本会先尝试 `mount -o remount,rw /`；若 remount 失败，仅本次启动，重启后需重新执行安装。

## 7. 访问与验证

安装结束会打印实际端口与所有可用 IP，例如：

```text
http://192.168.1.1/
http://192.168.1.1:8080/
```

常用检查：

```sh
<安装目录>/bin/fibowebctl status
cat <安装目录>/etc/port
cat <安装目录>/var/fiboweb.log
```

直接请求状态接口：

```text
http://<模组IP>:<端口>/fiboweb/status
```

返回型号、AT 通道（可能是 `ofono:/ril_0`）、端口、IP 列表与运行时长。现场自检：

```sh
<安装目录>/bin/fiboweb -selftest -state <安装目录>/etc
```

## 8. 端口与网络行为

- 固定绑定 `0.0.0.0`：路由模式从 LAN 口访问，网桥模式从桥接口地址访问。
- 端口自动选择：80（无冲突时）→ 8080 → 8000 → 8088。
- 若 UDX710 固件已有页面占用 80，本服务会落到 8080，两者互不影响。
- 安装脚本会为实际端口添加仅限私网来源的 iptables 放行规则（192.168/16、10/8、172.16/12、169.254/16）。
- 完全离线，不加载外部 CDN。

## 9. 卸载

```powershell
adb shell sh /data/local/tmp/fiboweb-install/uninstall.sh
```

可选：`KEEP_DATA=1` 保留配置与日志；`FIBOWEB_ROOT=/mnt/data/fibocom-webui` 指定安装目录。卸载会停止并删除 systemd / OpenWrt / `/etc/init.d/fiboweb` / `/etc/rc5.d/S99fiboweb` / rc.local 自启项及对应 iptables 规则。

## 10. 注意事项与能力边界

1. **AT 未就绪**：状态接口会提示“未找到可用的 AT 通道”。优先确认 ofono 是否运行（`pidof ofono`）以及 `gdbus`/`dbus-send` 是否存在；也可显式设置 `FIBOWEB_AT=/dev/ttyAT`。
2. **SELinux**：若为 Enforcing 且服务未监听端口，可先 `setenforce 0` 验证；安装脚本已尝试 `restorecon`。
3. **只读根分区**：自启依赖 remount 成功；失败时服务仅本次运行。
4. **功能边界**：设备信息、SIM/信号、网络注册、APN、短信、重启/恢复出厂等 AT 类页面可用；LAN/DHCP/WLAN/防火墙/PPPoE/VPN/UPnP 等配置页面后端未实现（返回空对象），会显示空值或默认值。
5. **恢复出厂**：安装目录可能在 `/mnt/data` 或 `/home/root`，恢复出厂/格式化用户分区会清除本项目，需要重新安装。
6. **升级/刷机**：前端在线升级页面返回“不支持”，请使用厂商升级工具。
7. **登录**：站点已做本地会话注入，打开即进入 `#/Home`，并取消 10 分钟自动注销。
