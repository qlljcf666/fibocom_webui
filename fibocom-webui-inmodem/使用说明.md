# Fibocom 模组内置原厂 WebUI（fibocom-webui-inmodem）使用说明

## 1. 项目作用

把原厂 WEBUI（`WEBUI_V_02.02.28`，104 个站点文件）通过 **adb** 安装到模组 Linux 内部，并自带一个纯 Go 静态后端：

- 提供 `/` 静态页面与 SPA 回退；
- 实现 `/fibo/webapi`（JSON-RPC）与 `/fibo/fibologin/`；
- 通过模组内部 AT 通道读取/设置模组状态；
- 绑定 `0.0.0.0`，不依赖互联网，路由模式、网桥模式只要拿到 `192.168.x.x` 地址即可访问。

因此 AT 类功能 **不依赖** 原厂固件里的 QCMAP、goahead、lighttpd 或 `libfibosocket`，可以直接装到没有内置 Web 的模组上；但 QCMAP 的 LAN/WLAN/防火墙配置页面不在本项目后端范围内（见 9.4）。

## 2. 适用模组

| 模组 | 架构 | 状态 | 说明 |
|---|---|---|---|
| FG132 | ARMv7 / ARM64 | 适配 | 5G RedCap，AT 指令按标准 3GPP + GT 回退处理 |
| FM150 | ARMv7 | 适配 | FM150AE（sdxprairie）实测；主 AT 为 `/dev/smd7`，常被 `fibo_at_client` 占用，建议 `FIBOWEB_AT=/dev/at_smd7` |
| FM160 | ARMv7 / ARM64 | 适配 | 常见 AT 通道 `/dev/smd11`、`/dev/smd9` |
| FM190 | ARMv7 / ARM64 | 适配 | 同上 |

其他 Fibocom 模组只要满足“可 adb root、有可写分区（`/usrdata`、`/data` 等）、Linux 内能打开 AT 通道”，也可以安装；程序不锁定型号。

### 2.1 FM150AE（sdxprairie）实测

对 `FM150AE-sdxprairie-sysfs.ubi`（SDX55 rootfs 镜像）解包确认：

- 32 位 ARM（ELF EM_ARM，EABI5）、systemd 239、hostname `sdxprairie`；
- 根分区只读，可写分区为 `/data`、`/customer`、`/persist`、`/systemrw`、`/fibocom`，没有 `/usrdata`；
- 镜像内没有 `webs`/`lighttpd` 与前端资源，80 端口空闲；
- QCMAP LAN 为 `192.168.225.1/24`，DHCP `192.168.225.20-60`，防火墙关闭；
- `fibo_at_client.service` 开机自启并占用 `/dev/smd7`。

## 3. 前置条件

1. `adb devices` 能看到设备，且具有 root 权限（多数模组 `adb root` 后即为 root）。
2. 模组内有可写且可执行的分区，优先 `/usrdata`，其次 `/data`、`/userdata`、`/opt`。
3. 目标端口空闲：默认按 `80 → 8080 → 8000 → 8088` 自动选择。
4. AT 通道未被其他常驻程序独占。

## 4. 安装方法

### 4.1 一键安装（推荐）

在 Windows 项目根目录：

```powershell
# 1) 构建 ARMv7/ARM64 二进制并组装 dist（也可直接双击 build.bat）
powershell -ExecutionPolicy Bypass -File .\build.ps1

# 2) 推送并安装
powershell -ExecutionPolicy Bypass -File .\tools\push.ps1

# 多设备或指定端口
powershell -ExecutionPolicy Bypass -File .\tools\push.ps1 -Serial <序列号> -Port 80
```

`push.ps1` 会自动识别 `uname -m`，只推送匹配的二进制，并逐文件推送 `www`，避免不同 adb 版本目录嵌套问题。

### 4.2 手动安装

如果不用 `push.ps1`，建议按“先建目录、再逐文件推送”的方式，避免不同 adb 版本对目录推送多套一层：

```powershell
adb root
adb shell "rm -rf /data/local/tmp/fiboweb-install; mkdir -p /data/local/tmp/fiboweb-install/bin /data/local/tmp/fiboweb-install/www"
adb push dist\bin\fiboweb-arm64 /data/local/tmp/fiboweb-install/bin/
adb push dist\install.sh /data/local/tmp/fiboweb-install/
adb push dist\uninstall.sh /data/local/tmp/fiboweb-install/

$www = (Resolve-Path "dist\www").Path
Get-ChildItem "dist\www" -Recurse -Directory | ForEach-Object {
    $rel = $_.FullName.Substring($www.Length).Replace('\','/')
    adb shell "mkdir -p '/data/local/tmp/fiboweb-install/www$rel'"
}
Get-ChildItem "dist\www" -Recurse -File | ForEach-Object {
    $rel = $_.FullName.Substring($www.Length).Replace('\','/')
    adb push $_.FullName "/data/local/tmp/fiboweb-install/www$rel"
}

adb shell sh /data/local/tmp/fiboweb-install/install.sh
```

安装脚本按 `/usrdata → /data → /userdata → /opt` 的顺序自动选择第一个可写分区。FM150AE 没有 `/usrdata`，实际安装到 `/data/fibocom-webui`。下文用 `<安装目录>` 表示该路径，脚本会生成：

| 文件 | 作用 |
|---|---|
| `<安装目录>/etc/listen` | 监听地址（默认 `auto`） |
| `<安装目录>/etc/port` | 实际监听端口 |
| `<安装目录>/etc/config.json` | AT 通道、语言、时区、短信中心 |
| `<安装目录>/bin/fibowebctl` | start/stop/restart/status |
| `<安装目录>/var/fiboweb.log` | 运行日志 |

## 4.3 图形化管理工具（GUI）

项目根目录提供 Windows 图形化操作界面，封装的仍是同一套 `build.ps1` / `push.ps1` / `fibowebctl`，适合不熟悉命令行的场景。

启动方式（任选其一）：

- 双击 `启动GUI.bat`：优先启动已打包的 `FibocomWebUI.exe`，没有 exe 时用 Python 运行源码；
- 直接双击 `FibocomWebUI.exe`；
- 源码运行：`python gui\fiboweb_gui.py`（需要 Python 3 与 tkinter，Windows 官方 Python 自带）。

主要功能：

| 功能区 | 功能 |
|---|---|
| 设备连接 | 自动列出 adb 设备、刷新、显示型号与授权状态 |
| 安装设置 | 监听端口（自动/80/8080/8000）、卸载时是否保留配置 |
| 操作 | 一键安装、重新构建并安装、打开管理页、启动/停止/重启、刷新状态、查看日志、卸载 |
| 状态面板 | 安装状态、WebUI 版本、实际端口、AT 通道、模组架构、访问地址、适配检测（安装目录/根分区只读/AT 占用） |
| 日志 | 实时显示 adb/构建/安装输出，支持清空 |

使用流程：

1. USB 连接模组，确认 `adb devices` 状态为 `device`；
2. 点击“刷新”，在下拉框选择设备；
3. 选择监听端口，点击“一键安装”（`dist` 不存在时会自动先构建）；
4. 点击“打开管理页”：工具会先执行 `adb forward`，再打开 `http://127.0.0.1:<本地端口>/`，**电脑与模组不在同一网段也能访问**；
5. 需要时使用启动/停止/重启、查看日志、卸载。

打包为单文件 exe（可选，需要 PyInstaller）：

```powershell
powershell -ExecutionPolicy Bypass -File .\gui\build_exe.ps1
# 产物：项目根目录 FibocomWebUI.exe
```

说明：exe 需与 `dist`、`build.ps1`、`tools\push.ps1` 位于同一项目根目录；GUI 不内嵌站点与 ARM 二进制，安装时使用项目内已构建的 `dist`。

## 5. 开机自启

安装脚本按目标系统自动选择：

1. **systemd**（`/run/systemd/system` 存在）：写入 `/etc/systemd/system/fiboweb.service`，`systemctl enable/restart`。FM150AE 等根分区默认只读的模组会先尝试 `mount -o remount,rw /`；单元中带 `RequiresMountsFor=<安装目录>` 与 `After=data-mount.service`，确保 `/data` 已挂载再启动。
2. **OpenWrt procd**（`/etc/rc.common`、`/etc/init.d` 存在）：写入 `/etc/init.d/fiboweb`，procd 托管。
3. **其他**：向 `/etc/rc.local` 追加启动块；若 `/etc` 只读且 remount 失败，则仅本次启动并给出提示。

## 6. 访问与验证

安装结束会打印实际端口与所有可用 IP，例如：

```text
http://192.168.1.1/
http://192.168.1.1:8080/
```

常用检查：

```sh
<安装目录>/bin/fibowebctl status
cat <安装目录>/etc/port
cat <安装目录>/var/fiboweb.log
```

也可以直接请求：

```text
http://<模组IP>:<端口>/fiboweb/status
```

返回内容包含型号、AT 通道、端口、IP 列表与运行时长。若 AT 通道探测失败，可现场执行：

```sh
<安装目录>/bin/fiboweb -selftest -state <安装目录>/etc
```

## 7. 端口与网络行为

- 服务固定绑定 `0.0.0.0`，路由模式下从 LAN 口访问，网桥模式下从桥接口地址访问。
- 端口自动选择：80（无冲突时与原厂地址一致）→ 8080 → 8000 → 8088。
- 若模组已有原厂 Web 占用 80/443，本服务会落到 8080，二者互不影响。
- 安装脚本会为实际端口添加仅限私网来源的 iptables 放行规则（192.168/16、10/8、172.16/12、169.254/16）。
- 完全离线可用，不加载任何外部 CDN。

## 8. 卸载

```powershell
adb shell sh /data/local/tmp/fiboweb-install/uninstall.sh
```

可选：`KEEP_DATA=1` 保留配置与日志；`FIBOWEB_ROOT=/data/fibocom-webui` 指定安装目录。

## 9. 注意事项

1. **AT 通道**：默认依次探测 `/dev/smd11`、`/dev/smd9`、`/dev/at_smd7`、`/dev/smd7`、`/dev/smd8`、`/dev/smd10`、`/dev/smd6`、`/dev/smd5`、`/dev/smd23`、`/dev/at_mdm0`、`/dev/at0`、`/dev/at_usb0`、`/dev/ttyMSM1`、`/dev/ttyGS0`、`/dev/ttyHS0`、`/dev/ttyMSM0`。FM150AE 上 `/dev/smd7` 常被开机的 `fibo_at_client.service` 占用；若 AT 响应不稳定，可设置 `FIBOWEB_AT=/dev/at_smd7`，或执行 `systemctl stop fibo_at_client` 后重启本服务。也可用 `FIBOWEB_AT=/dev/smdX` 或修改 `etc/config.json` 覆盖。
2. **SELinux**：FM150AE 为 `enforcing` + `mls`，且镜像内没有 `getenforce`。安装脚本会读取 `/sys/fs/selinux/enforce` 判断并执行 `restorecon`；若服务未监听端口，可先 `setenforce 0` 验证是否为策略拦截，正式环境需自行添加策略。
3. **只读根分区**：安装脚本会在写 systemd 单元前尝试 `mount -o remount,rw /`；若 remount 成功则自启可持久化，失败则仅本次启动，重启后需重新执行安装。
4. **功能边界**：设备信息、SIM/信号、网络注册、APN、短信、重启/恢复出厂等 AT 类页面可用；LAN/DHCP/WLAN/防火墙/PPPoE/VPN/UPnP 等 QCMAP 配置页面后端未实现（返回空对象），页面会显示空值或默认值。FM150AE 的 QCMAP 实际在运行（`QCMAP_ConnectionManagerd.service`），如需这些页面需接入 `QCMAP_Web_CLIENT`。
5. **恢复出厂**：安装目录在 `/data`（userdata 卷），恢复出厂或擦除 userdata 会清除本项目，需要重新安装。
6. **升级/刷机**：前端中的在线升级页面返回“不支持”，请使用厂商升级工具。
7. **登录**：站点已做本地会话注入，打开即进入 `#/Home`，并取消了 10 分钟自动注销。
